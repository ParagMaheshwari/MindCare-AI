CONFIDENTIALITY & ARCHITECTURE

Privacy & Data Security First

Mental wellness data is deeply sensitive. MindCare AI is architected around transparent boundaries, local-first client storage, cryptographic protection, and backend-shielded AI proxies.

Local-First Storage

On-device browser persistence

Assessment responses, personal journal notes, and daily mood logs are saved directly in your browser's localStorage. Guests can take assessments and use tools entirely without transmitting personal profiles.

Client-Side Cryptography

SHA-256 Web Crypto hashing

When creating an account or authenticating, passwords undergo one-way cryptographic hashing client-side using the browser's native Web Crypto API (SHA-256) before transmission, preventing plaintext exposure across network boundaries.

Isolated AI Proxy Gateway

No client-side API credentials

All conversational interactions with Google Gemini AI are routed through our backend server (FastAPI). Gemini API credentials remain isolated on the server and are never bundled, transmitted, or accessible via browser dev tools.

Zero Third-Party Trackers

No ad networks or data brokering

MindCare AI does not include marketing tracking pixels, advertising SDKs, social trackers, or data-brokering scripts. Your habit evaluations and mood check-ins are not monetized or sold to third-party advertisers.

Implemented Security Architecture

✓
Transparent Data Boundary: The Machine Learning model operates as a trained Random Forest Regressor analyzing numerical behavioral attributes (sleep hours, screen time, physical exercise, study habits). It does not require government IDs, biometric data, or financial information.
✓
User-Controlled Data Purge: You have the ability to clear your stored assessment drafts, delete local session storage, or log out of your profile at any time.
✓
Server-Side Password Protection: On the backend database, user records are isolated and protected. Password hashes are stored securely rather than in cleartext.
