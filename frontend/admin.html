Central Data Storage Architecture

MindCare AI implements a zero-leakage, IDOR-protected relational backend storage layer. Every assessment submission, mood check-in, journal entry, and goal is securely persisted with user ownership validation.

🔒 Authentication & RBAC
Bcrypt password hashing (work factor 12). JWT token verification enforces role-based access control (User vs Administrator).
🛡️ IDOR & Data Isolation
Direct object references are isolated per-user token claims. Non-admin users cannot query or mutate foreign account records.
⚡ Cloud State Rehydration
Client localStorage acts as an instantaneous reactive UI cache. Clearing browser storage instantly rehydrates full state upon login.
